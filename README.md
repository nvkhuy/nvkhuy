### 👨🏻‍💻 About Me

I am a Software Engineer who bridges **Applied Machine Learning & Agentic Systems**, **High-Throughput Backend Infrastructure**, and **Native iOS Craftsmanship**. 

* 🤖 **Agentic Engineering & LLMs:** Designing and implementing autonomous agent workflows with custom tool integrations, automated test generation, and evaluation suites that benchmark task completion rates and enforce schema adherence.
* 🧠 **Synthetic Data & Model Evaluation:** Building synthetic data generation engines to overcome training scarcity, converting unstructured documents and chats into instruction datasets, and qualifying model outputs with hallucination guardrails.
* 📱 **iOS Indie Development:** Creator and publisher of standalone games on the Apple App Store, with end-to-end ownership spanning custom haptic feedback, fluid 60 fps render loops, generative AI art direction, and TestFlight release pipelines.
* ⚡ **Distributed Backend Systems:** Scaling order processing pipelines and high-throughput log collection in Python and Go, using Kafka, Redis, and PostgreSQL to deliver subsecond response times under peak regional loads.
